# ABU Wallet Tool / ABU 钱包工具

English
-------
ABU (Alpha Bank Union) Wallet Tool is a personal wallet client for managing Alpha Coin transactions on the GeoPolyCraft Minecraft server. It allows players to securely send and receive coins, maintain a local transaction ledger, and participate in the anti-counterfeiting mechanism of the ABU system.

Main features:
- Generate and sign transactions, package them as ZIP files for sharing.
- Import and verify incoming transactions, including signature validation and optional blacklist check.
- Store all transaction history in a local SQLite database (`~/.abu/personal_wallet.db`).
- Export all transaction data as JSON evidence for anti-counterfeiting arbitration.
- Import ABU-issued blacklist to warn against suspicious addresses.
- View a simple chart of recent transactions and current balance.

Quick start:
```bash
cargo build --release
cargo run --release
```

Notes:
- Before first use, you must import your personal private key and public key (generated by `abu-keygentool`). The private key will be stored encrypted in `~/.abu/my_secret_key.bin`.
- When sending a transaction, a ZIP file is created containing the transaction JSON and your public key. Send this file to the recipient.
- Upon receiving a transaction, after validation, the tool generates a receipt ZIP containing the transaction with your signature. Send it back to the sender to complete the process.
- All trusted public keys from others are saved in `~/.abu/trusted_pubkeys/` for future use.

Security:
- Private keys are never stored unencrypted; they are decrypted in memory only when needed and cleared immediately.
- Always back up your private key file and remember your password. Losing them means losing access to your funds.
- The wallet uses the same key format as `abu-keygentool` (PBKDF2-SHA256 + AES-GCM encrypted).

中文（Chinese）
----------------
ABU（Alpha Bank Union）钱包工具是为 GeoPolyCraft 我的世界服务器中的 Alpha Coin 系统开发的个人钱包客户端。玩家可以安全地收发货币，维护本地交易账本，并参与 ABU 体系的防假币机制。

主要功能：
- 生成并签名交易，打包为 ZIP 文件供发送。
- 导入并验证收到的交易，包括签名验证和黑名单检查。
- 将所有交易历史存储在本地 SQLite 数据库（`~/.abu/personal_wallet.db`）中。
- 导出全部交易数据为 JSON 证据文件，用于防假币仲裁。
- 导入 ABU 发布的黑名单，对可疑地址进行风险提示。
- 查看近期交易简图及当前余额。

快速开始：
```bash
cargo build --release
cargo run --release
```

说明：
- 首次使用前，需导入由 `abu-keygentool` 生成的个人私钥和公钥。私钥将加密存储在 `~/.abu/my_secret_key.bin` 中。
- 发送交易时，工具会生成一个 ZIP 包，内含交易 JSON 及你的公钥。请将此文件发送给收款方。
- 收到交易后，验证通过时工具会生成回执 ZIP（包含你签名的交易）。请将其发回给付款方，以完成交易流程。
- 其他人的信任公钥会自动保存在 `~/.abu/trusted_pubkeys/` 目录中，以备将来使用。

安全提示：
- 私钥始终加密存储，仅在需要时解密到内存并立即清零。
- 务必离线备份私钥文件并牢记密码。私钥丢失将导致资金永久无法访问。
- 本钱包使用与 `abu-keygentool` 相同的密钥格式（PBKDF2-SHA256 + AES-GCM 加密）。

本软件专为 GeoPolyCraft（我的世界服务器）中的玩家设计，仅供该用途。请勿将其直接用于其他生产系统，除非已审查并按需增强安全性。
